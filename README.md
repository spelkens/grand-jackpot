# Le Grand Jackpot

Jeu de questions pour live TikTok. Le serveur lit le chat (réponses A, B, C, D) et les cadeaux du live, et les envoie au jeu en direct.

- `public/index.html` : le jeu
- `server.js` : le serveur (page + liaison TikTok)
- Hébergement gratuit : Render (fichier `render.yaml`)

Variable facultative : `EULER_API_KEY` (clé gratuite Euler Stream si la connexion au live est limitée).
